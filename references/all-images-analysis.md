# 18张素材逐图风格分析

本轮逐张查看原图后建立独立档案。以下名称为描述性的工作名称，不是艺术史流派鉴定。目录旧文件夹按题材归档，仅用于定位；真正的风格匹配采用各档案中的视觉机制。

| [R01 疏空渐层与异质断面](image-profiles/R01.md) | 平静、近乎无纹理的空域，与内部极其复杂的薄片状断面并置；复杂性被局限在一侧。 | 仅称极简风会丢失断面密度；仅称水墨会丢失彩膜与颗粒；R13同有线与留白，但其硬直冲突与本图缓慢承托不同。 |
| [R02 虚实游移的灰阶动作笔触](image-profiles/R02.md) | 宽灰拖痕与窄白擦痕在黑场中旋动；清楚的局部痕迹无法拼成稳定的整体实体。 | 不是凡有旋转都等于此风格；霓虹虫洞、光滑同心环、整体高斯模糊都会消灭其笔触与不完整性。 |
| [R03 全幅游线与局部金黄凝聚](image-profiles/R03.md) | 背景和主体都被同一套游走线迹贯穿，金黄色局部与大范围绿色形成聚焦。 | 不是发光树风格，也不应默认胸前光球或母子叙事；不能把绿色与圆环当作不可替换的标配。 |
| [R04 黑底金线与横向回旋](image-profiles/R04.md) | 体积由密集金色长线累积而成，外侧长带与圆弧把局部形体扩成有方向的运动场。 | 不能把所有回环都读成枷锁；与R06虽有细线却一外放一内收，直接平均会损失个性。 |
| [R05 黑白满幅复调线迹](image-profiles/R05.md) | 粗白环团、细线网络、尖角星形和亮点同时争夺注意力，中央小轮廓被复杂场包围。 | 只称极简黑白会严重错判；和R02同是灰阶但一满一空、一碎一缓，不宜直接混为同一种梦幻。 |
| [R06 低照度蓝紫纤维与水平余痕](image-profiles/R06.md) | 大部分线迹压入黑暗，中央蓝紫色凝聚与底部横向痕迹建立安静的上下关系。 | 不等于R04换成蓝色：两者空场比例、线长方向和能量分布都不同；别默认能量人体。 |
| [R07 冷灰软焦与近距离遮蔽](image-profiles/R07.md) | 画面大结构可以辨认，局部身份却被软焦和巨大近景暗块遮住，紧张来自看不清。 | 仅称低对比雾景不准确：暗亮分区明显；与R02的笔触失边机制不同，不可互相替代。 |
| [R08 湿润硬表面与细粒散布](image-profiles/R08.md) | 规则台阶与石面肌理提供稳定几何，花瓣和枝条以细碎不规则性打破秩序。 | 花瓣题材不等于R12的近景阳光风格；不是稀疏极简，微粒也是主体的一部分。 |
| [R09 暗底繁彩与悬粒景深](image-profiles/R09.md) | 高彩度的多尺度形体从下方拥上来，黑暗上半部又被小亮点填充，呈现浓密而非空灵。 | 不能把它与R08、R12合成一个花影风；整体黑暗不等于低能量、宁静。 |
| [R10 重复透视与半透明时间叠层](image-profiles/R10.md) | 同一类建筑模块与人影被不断重复、错位和透明覆盖，几何空间因时间痕迹变得不稳定。 | 不是普通的大建筑小人物；与R18的硬边照片叠置不同，这里多层图像互相渗透。 |
| [R11 限色海报与尖锐前景](image-profiles/R11.md) | 大红底、黑色斜切线网、少量刺白亮点与中央深色体块形成紧迫的图形冲突。 | 并非任何哲理都适合红黑海报；白环、带刺线、仰首人物是具体符号，不是必需的风格骨架。 |
| [R12 暖侧光的浅色近景与清空背景](image-profiles/R12.md) | 细薄柔软的近景体积在暖光中有清楚触感，上方蓝色空域让它显得明朗而轻。 | 不是泛泛日系滤镜；仅用粉蓝配色而丢掉花瓣式薄面塑光，难以还原其触感。 |
| [R13 红白硬边碎片与透视穿行](image-profiles/R13.md) | 大批锐角带状形体和字形沿深透视分布，中央暗红球提供稳点，运动来自尺度骤变。 | 和R11仅共享红白黑与锐利，空间规则不同；把它纳入R02柔性梦感会改变核心机制。 |
| [R14 逆光实景与前景半透明纹层](image-profiles/R14.md) | 树叶天空仍可辨认，而近处红橙弧状细纹让观看像隔着一层可感知的介质。 | 不能仅称夕阳草地；红色弧纹是主要机制，却不宜擅自认定具体材料。 |
| [R15 单色层峦与硬剪影](image-profiles/R15.md) | 同色系远景不断降低对比和细节，前景则压成近黑硬形，让辽阔与稳定锚点并存。 | 不是用了蓝色就有辽阔；核心是层间对比差、遮挡与硬软远近规律。 |
| [R16 暖色柔光成像与外层观看框](image-profiles/R16.md) | 内层是有体积的动画式环境和柔光人物；外层有圆角黑框、旋转与屏幕观看痕迹，两者必须分开。 | 不能把屏摄边框、压缩和方向误作核心艺术风格；也不应把一切CG感一概排除，本图体积柔光正是特征。 |
| [R17 暗空中的断续光迹](image-profiles/R17.md) | 少量爆散轨迹和微弱烟影在巨大黑场里短暂留下痕迹，视觉力量来自稀疏和衰减。 | 不能把所有放射都称虫洞；也不能加满星点来增加梦幻，会破坏本图稀疏。 |
| [R18 硬边照片叠置与暗调日常](image-profiles/R18.md) | 多张独立影像靠硬边遮挡形成层次，照片身份保持完整，整体暗调把不同场景统一。 | 不是R10那种互相渗透的叠影，也不是R16单个画面被屏幕包围；不能随意加撕纸与胶片颗粒。 |

## 证据边界

直接所见：形体、色彩、轮廓、清晰度、叠压、粒度、光区分布。感知解释：虚渺、温暖、紧迫、孤寂等，需要结合文字使用。制作推测：像干擦、像多重曝光、像动画渲染，仅作外观描述，不断言实际工艺。没有通过联网追溯作者或制作教程，也没有用风格词代替图像观察。
