# R06｜低照度蓝紫纤维与水平余痕

[打开参考原图](../../assets/visual-reference-library/线与人物/1793461893604.png) · 原文件：1793461893604.png

**核心构成**：大部分线迹压入黑暗，中央蓝紫色凝聚与底部横向痕迹建立安静的上下关系。

**所见题材（不随风格自动迁移）**：中央偏下蓝紫蜷坐人形轮廓，周围暗线向外游走，下方有反射状横向线域。

## 风格证据

| 维度 | 观察与分析 |
|---|---|
| 构图与留白 | 竖幅主体落在下半，头顶大片暗空；上方线迹极稀，下方密度加大，重心低。 |
| 色彩与明度 | 近黑背景配窄域蓝紫；主体局部偏青蓝，少量灰色纤维几乎隐没。 |
| 笔触与形状 | 极细线有交错与断续，主体内部由点、短线和薄涂累积；下部多横向痕迹。 |
| 边缘与清晰度 | 主体边缘被线纤维松开，头部部分消失于暗场；仍有可辨形态，不是完全无物。 |
| 空间机制 | 下部有表面或倒影的暗示，但无法确认真实水面；远处不设清晰环境。 |
| 运动与节奏 | 中心相对静定，周围细线缓慢扩散，水平痕迹压低外放的速度。 |
| 材料外观与不确定性 | 像半透明纤维层与冷色颜料、点粒混合；不宜直接称玻璃或真实丝线。 |
| 亮度与光学 | 有蓝紫色辉光感与下方映照，亮区小且受控，不能扩展成全幅霓虹。 |

## 感知与文字匹配

内收、静默、幽微的存在感；形体既有凝聚又有消隐。

适合微弱留存、孤寂、沉潜或似有若无；可只取低照度和纤维凝聚，无需坐姿与水面。

## 容易误判之处

不等于R04换成蓝色：两者空场比例、线长方向和能量分布都不同；别默认能量人体。
