# R04｜黑底金线与横向回旋

[打开参考原图](../../assets/visual-reference-library/线与人物/1793461857159.png) · 原文件：1793461857159.png

**核心构成**：体积由密集金色长线累积而成，外侧长带与圆弧把局部形体扩成有方向的运动场。

**所见题材（不随风格自动迁移）**：持剑人形以金线构成，左上剑形斜伸，右侧与上部有横向长回环。

## 风格证据

| 维度 | 观察与分析 |
|---|---|
| 构图与留白 | 横幅中央偏左密集，右方长线在黑底中舒展；斜线、竖直形体与水平回环相互制衡。 |
| 色彩与明度 | 黑底配金黄、赭金与少量灰白细线，亮部饱和集中，外围线条暗得多。 |
| 笔触与形状 | 细长线构成纤维般体积，粗细金带与极细圆弧并用；弧线常连续延伸到画外。 |
| 边缘与清晰度 | 轮廓被线迹拆开，内部也有空隙；边缘锋利的细线和厚带拖痕共存。 |
| 空间机制 | 线迹通过前后穿插形成浅纵深，黑底没有清楚场景；非写实地面与天空。 |
| 运动与节奏 | 横向回旋、向上甩动和左上斜伸同时存在，长线使画面有持续的速度感。 |
| 材料外观与不确定性 | 有金属丝与金色绘画拖痕的混合外观；仅从图不能确认真实金属或笔刷。 |
| 亮度与光学 | 主体密处累积高亮，暗场托起金色；不必解释为人物真的在发光。 |

## 感知与文字匹配

外放、昂扬、锋利的意志与牵引；原图是否束缚不确定，回环也可读成运动轨迹。

适合张力、延展、奔涌与相互牵引；借长线方向与密度累积，不默认持剑人、金色或捆绑。

## 容易误判之处

不能把所有回环都读成枷锁；与R06虽有细线却一外放一内收，直接平均会损失个性。
