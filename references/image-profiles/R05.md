# R05｜黑白满幅复调线迹

[打开参考原图](../../assets/visual-reference-library/线与人物/1793461874111.png) · 原文件：1793461874111.png

**核心构成**：粗白环团、细线网络、尖角星形和亮点同时争夺注意力，中央小轮廓被复杂场包围。

**所见题材（不随风格自动迁移）**：多种圆团、环线、四角形与星状亮点；中部有较小人形轮廓，背景密布小白点。

## 风格证据

| 维度 | 观察与分析 |
|---|---|
| 构图与留白 | 竖幅近满铺，大小白团围绕中部相对疏区；有中央落点但没有唯一主角，眼睛不断跳转。 |
| 色彩与明度 | 强烈黑白对照，保留灰色排线；部分亮点明显溢亮，局部高亮远强于线团。 |
| 笔触与形状 | 粗涂圆团、细密连线、尖锐四角标记和小点是四种不同尺度语汇，叠压层数多。 |
| 边缘与清晰度 | 大多数标记较锐利，粗笔内部仍有干刷破口；并非雾化柔软。 |
| 空间机制 | 环线与大小差异暗示前后，但图形叠加和浅平面密度同样强；空间在装饰面与深场之间摇摆。 |
| 运动与节奏 | 多中心旋绕、互相穿越，非单一旋涡；密度过载使观看节奏碎而快。 |
| 材料外观与不确定性 | 涂抹、排线与数码亮点混用的外观；材料感不统一正是其复调特点。 |
| 亮度与光学 | 有明确星芒式亮点和泛白中心，不能像R02那样只按哑光白颜料描述。 |

## 感知与文字匹配

眩目、繁复、拥挤、漫游或失序；“孤独”只是可能读法，不能自动决定。

适合过量、万端并起、繁复关联；控制图形词汇数和密度即可迁移，不必带入星星与人形。

## 容易误判之处

只称极简黑白会严重错判；和R02同是灰阶但一满一空、一碎一缓，不宜直接混为同一种梦幻。
