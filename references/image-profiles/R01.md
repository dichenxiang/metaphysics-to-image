# R01｜疏空渐层与异质断面

[打开参考原图](../../assets/visual-reference-library/边界与留白/1793460670162.png) · 原文件：1793460670162.png

**核心构成**：平静、近乎无纹理的空域，与内部极其复杂的薄片状断面并置；复杂性被局限在一侧。

**所见题材（不随风格自动迁移）**：细树、小鸟、低日轮与水平界面；左下是不规则透明色片、黑色结块及垂落细线。

## 风格证据

| 维度 | 观察与分析 |
|---|---|
| 构图与留白 | 竖幅中水平界面位于上半部；密集体块贴左、向下伸展，右方大面积留空；微小轮廓与厚重断面悬殊。 |
| 色彩与明度 | 背景从冷淡蓝经粉橙过渡到灰绿；局部红、青、黑高纯度堆积，形成广域低彩与小域强彩。 |
| 笔触与形状 | 下部大块半透明膜片、碎裂色面、粗粝结块与极细游丝并存；树枝重复了细线语汇。 |
| 边缘与清晰度 | 空域连续柔滑，薄片边缘有细黑勾线与硬软转换，黑色肌理局部破碎。 |
| 空间机制 | 上方有可读的天际，下方突然转入非写实剖面；像地形又像半透明拼贴，空间系统跨界。 |
| 运动与节奏 | 整体静止；细线向下延长和密团坠落倾向提供缓慢的牵引，水平线维持平衡。 |
| 材料外观与不确定性 | 接近薄层染色、透明膜片与粗颗粒拼贴的混合外观；不能据此确认真实材料。 |
| 亮度与光学 | 日轮附近亮而偏暖；大部分画面没有强烈立体投影，下部更多依靠色块叠压。 |

## 感知与文字匹配

轻与重、表面静与内部繁复并存；可感悬置和脆弱，不必解读为悲伤。

适合表里、轻重、显露与隐含等关系；迁移空域／密域的不对称和薄膜层次，无需保留树、鸟和太阳。

## 容易误判之处

仅称极简风会丢失断面密度；仅称水墨会丢失彩膜与颗粒；R13同有线与留白，但其硬直冲突与本图缓慢承托不同。
