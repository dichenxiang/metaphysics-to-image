# R10｜重复透视与半透明时间叠层

[打开参考原图](../../assets/visual-reference-library/暗场与张力/1793461965916.png) · 原文件：1793461965916.png

**核心构成**：同一类建筑模块与人影被不断重复、错位和透明覆盖，几何空间因时间痕迹变得不稳定。

**所见题材（不随风格自动迁移）**：建筑内厅、上方冷白竖条阵列、层层台阶与许多大小不同的人影。

## 风格证据

| 维度 | 观察与分析 |
|---|---|
| 构图与留白 | 竖幅近中轴，亮条聚集在上部中心，越向下人物和空间铺得越广；两侧暗立面收束。 |
| 色彩与明度 | 顶部青白、下部黄褐与黑绿边缘，冷暖沿纵深过渡，整体低彩度。 |
| 笔触与形状 | 竖条与水平层级精确重复，人物是半透明块影；横向细线和重影覆盖几何。 |
| 边缘与清晰度 | 上方模块较硬、重复轮廓清楚，下部人影拖长并淡化；重复不等于单纯失焦。 |
| 空间机制 | 多层尺度与透视嵌套形成深度，但错位覆盖打破单一一致视点；时间像被压进空间。 |
| 运动与节奏 | 人影残迹和重复层有流动感，建筑保持轴线稳定，静动同时存在。 |
| 材料外观与不确定性 | 多重曝光／图层错位般外观；不能仅凭成图确认慢门或具体合成技术。 |
| 亮度与光学 | 上部冷白阵列和下部暖亮层面引导视线，两侧暗部加强通道感。 |

## 感知与文字匹配

重复、群体流逝、秩序中的失重或异化，既有宏大也有不稳定。

适合循环、重叠、时间累积和个体消隐；迁移模块重复与透明叠层，可不使用建筑和人群。

## 容易误判之处

不是普通的大建筑小人物；与R18的硬边照片叠置不同，这里多层图像互相渗透。
