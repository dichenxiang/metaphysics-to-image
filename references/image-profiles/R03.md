# R03｜全幅游线与局部金黄凝聚

[打开参考原图](../../assets/visual-reference-library/线与人物/1793460721720.png) · 原文件：1793460721720.png

**核心构成**：背景和主体都被同一套游走线迹贯穿，金黄色局部与大范围绿色形成聚焦。

**所见题材（不随风格自动迁移）**：深红褐人形轮廓、向右伸展的黑色发状线；金黄椭圆与胸前较小亮形体；小形体具体身份不确定。

## 风格证据

| 维度 | 观察与分析 |
|---|---|
| 构图与留白 | 竖向主体占中下部，大椭圆围合中央；背景没有真正空白，主体周围仍有大片较松的线迹区。 |
| 色彩与明度 | 多层绿由灰绿转鲜绿，暗红褐主体与黄环对照；黄色同时作轮廓焦点与内部焦点。 |
| 笔触与形状 | 长短弯曲线、弧形刮痕、短排线交织，主体以更密集的线叠成，缺少精细五官塑形。 |
| 边缘与清晰度 | 人物外缘可辨又有线迹外溢；背景和主体纹理互相穿越，实体与环境并非完全分离。 |
| 空间机制 | 大多是浅层叠加的绘画空间，椭圆具有围合感但不是可计算的三维壳体。 |
| 运动与节奏 | 发状线横向伸出，椭圆回环，背景短线多向游走，动向在主体附近聚合。 |
| 材料外观与不确定性 | 像刮擦、排线与半透明涂层混合的绘画表面；不是纯净矢量线稿。 |
| 亮度与光学 | 黄形体靠高明度和色彩跳出；绿色也有明暗起伏，没有一致的写实光源解释全部亮区。 |

## 感知与文字匹配

围合、内外相通、保护或执念均可成为解读；不可把小亮形体断言成特定故事。

适合包容、缠绵、内外互渗；可迁移线迹贯通与局部凝聚，去掉人物、圆环后仍可成立。

## 容易误判之处

不是发光树风格，也不应默认胸前光球或母子叙事；不能把绿色与圆环当作不可替换的标配。
