# R07｜冷灰软焦与近距离遮蔽

[打开参考原图](../../assets/visual-reference-library/暗场与张力/1793461933609.png) · 原文件：1793461933609.png

**核心构成**：画面大结构可以辨认，局部身份却被软焦和巨大近景暗块遮住，紧张来自看不清。

**所见题材（不随风格自动迁移）**：右侧近景暗轮廓占据大半画面，左方有较远的手状或人形轮廓；背景亮域冷蓝，具体身份和动作不确定。

## 风格证据

| 维度 | 观察与分析 |
|---|---|
| 构图与留白 | 横幅右重左轻，近景大暗块切入并截断空间；远处小轮廓被压向左下。 |
| 色彩与明度 | 冷蓝灰、炭黑和少量偏绿暗色，低饱和；明暗差虽大但边界很软。 |
| 笔触与形状 | 看不见主导性的绘画线稿；主要是融化的色块、拖曳边缘和模糊层。 |
| 边缘与清晰度 | 全局清晰度低，但不同大小轮廓仍分层；局部重影或形变感不可等同于一张统一模糊蒙版。 |
| 空间机制 | 近大远小和重叠遮挡仍成立，深度来自摄影般视距；真实场景内容难以确认。 |
| 运动与节奏 | 模糊轮廓有不稳定和晃动感，未能从静帧确定拍摄运动方式。 |
| 材料外观与不确定性 | 软焦影像或绘画化影像的外观，不能判断是镜头失焦、后期还是生成结果。 |
| 亮度与光学 | 左后方大面积冷色漫射亮区，近景深黑；不是孤立亮线或自发光物。 |

## 感知与文字匹配

陌生、窥见、压近、记忆失真或不安梦感；并非温柔的朦胧。

适合认知不确定、看不真切、距离受阻；借遮蔽比例与分层软焦，不默认人影或恐怖情节。

## 容易误判之处

仅称低对比雾景不准确：暗亮分区明显；与R02的笔触失边机制不同，不可互相替代。
