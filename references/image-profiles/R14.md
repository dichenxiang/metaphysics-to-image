# R14｜逆光实景与前景半透明纹层

[打开参考原图](../../assets/visual-reference-library/自然与瞬息/1793462053931.png) · 原文件：1793462053931.png

**核心构成**：树叶天空仍可辨认，而近处红橙弧状细纹让观看像隔着一层可感知的介质。

**所见题材（不随风格自动迁移）**：仰向树丛、蓝天暖云、低位太阳；下半大片红橙弧形细纹，具体是网、反射或后期未知。

## 风格证据

| 维度 | 观察与分析 |
|---|---|
| 构图与留白 | 竖幅上部深色叶簇，低处中心亮光；前景曲线向亮处收拢，上部左侧有天空开口。 |
| 色彩与明度 | 绿黑叶影、蓝天、桃色云与红橙前景，冷暖分处不同深度，金白太阳连接两层。 |
| 笔触与形状 | 实景叶片细节与半透明重复弧纹并置，下部线纹有细碎亮点和柔化拖痕。 |
| 边缘与清晰度 | 叶片部分较锐，前景红纹部分柔散，耀斑附近局部失去细节；全图并非统一柔焦。 |
| 空间机制 | 实景远近层与贴近镜头的透明纹层相叠，产生隔着介质观看的深度。 |
| 运动与节奏 | 前景弧纹有回环牵引，实景静止，微光让运动像来自观看介质。 |
| 材料外观与不确定性 | 摄影式环境与透明网纹／光学叠层混合外观，不能确认为蛛网或确切滤镜。 |
| 亮度与光学 | 有明确太阳逆光，亮边、色散样彩斑和部分泛光可见；光确实影响环境。 |

## 感知与文字匹配

温热、包覆、恍惚或感官被染色的梦感；比R02更有身体温度与实景根基。

适合渗透、温暖的虚实交界或观看受介质改变；可迁移前景纹层与远景的焦点差，不需要树与太阳。

## 容易误判之处

不能仅称夕阳草地；红色弧纹是主要机制，却不宜擅自认定具体材料。
