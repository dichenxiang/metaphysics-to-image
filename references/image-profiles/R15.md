# R15｜单色层峦与硬剪影

[打开参考原图](../../assets/visual-reference-library/远景与行旅/1793462057595.png) · 原文件：1793462057595.png

**核心构成**：同色系远景不断降低对比和细节，前景则压成近黑硬形，让辽阔与稳定锚点并存。

**所见题材（不随风格自动迁移）**：蓝色层叠山峰、雾谷，前景岩石与持剑戴笠人物的黑色轮廓。

## 风格证据

| 维度 | 观察与分析 |
|---|---|
| 构图与留白 | 竖幅远景占大部，人物与黑岩在下半偏右，顶部空域渐亮，峰群层层重复。 |
| 色彩与明度 | 蓝青单色系，由近黑蓝递向淡灰蓝；几乎没有暖色支点。 |
| 笔触与形状 | 山体内部保留细纹理，远处转成简化面；前景轮廓高度概括，非密集线构成。 |
| 边缘与清晰度 | 近处轮廓很硬，远山逐层软化；远近清晰度与明暗递减一致。 |
| 空间机制 | 空气透视清楚，山谷雾层充当分隔；即使抽走人物，远景层次依然成立。 |
| 运动与节奏 | 层峦主要横向静定，人物衣带提供少量侧向动态；观看节奏缓慢展开。 |
| 材料外观与不确定性 | 景观概念绘画／渲染般外观，不能据图认定真实摄影或水墨画材。 |
| 亮度与光学 | 远处偏右上更亮，前景逆光剪影；没有明确单一日轮或发光线条。 |

## 感知与文字匹配

辽远、肃静、孤高或决意；武侠语义来自人物服饰，不应与空气透视绑定。

适合遥远、层层无尽、尺度差与静观；借单色层叠可用于非山水形态，不默认人物。

## 容易误判之处

不是用了蓝色就有辽阔；核心是层间对比差、遮挡与硬软远近规律。
