# R17｜暗空中的断续光迹

[打开参考原图](../../assets/visual-reference-library/暗场与张力/1793462092111.png) · 原文件：1793462092111.png

**核心构成**：少量爆散轨迹和微弱烟影在巨大黑场里短暂留下痕迹，视觉力量来自稀疏和衰减。

**所见题材（不随风格自动迁移）**：右上偏中的烟火样放射轨迹，灰烟与零散亮点，其余多为黑色。

## 风格证据

| 维度 | 观察与分析 |
|---|---|
| 构图与留白 | 横幅明显偏右上，不完整放射枝越出上缘；左侧与下部大空域使出现显得短促。 |
| 色彩与明度 | 黑与暗灰为主，亮迹偏暖白金，彩度低；没有R05满场强白块。 |
| 笔触与形状 | 细长轨迹由断续亮粒组成，有粗细和长短差；底部烟影柔散，非清楚绘画笔痕。 |
| 边缘与清晰度 | 亮粒有的锐、有的拖曳，烟雾低清晰度；不同痕迹衰减程度不同。 |
| 空间机制 | 无地面和尺度，深度靠烟影遮挡与亮暗；更像空中一刻而非构造空间。 |
| 运动与节奏 | 向外放射的轨迹暗示爆散，渐暗和断续让运动同时指向消逝；静帧不能确定曝光参数。 |
| 材料外观与不确定性 | 摄影或视频帧样光迹与烟影，具体曝光时间、镜头、烟火类型未知。 |
| 亮度与光学 | 实际明亮痕迹与暗烟相关联，局部有发光外观；与R02哑光笔痕的明度机制不同。 |

## 感知与文字匹配

短促、余响、绽现后的空旷；不必宏大或节庆。

适合刹那、消逝、余留与微小发生；迁移少量高亮和断续衰减，不必画烟花。

## 容易误判之处

不能把所有放射都称虫洞；也不能加满星点来增加梦幻，会破坏本图稀疏。
