# R13｜红白硬边碎片与透视穿行

[打开参考原图](../../assets/visual-reference-library/边界与留白/1793462046928.png) · 原文件：1793462046928.png

**核心构成**：大批锐角带状形体和字形沿深透视分布，中央暗红球提供稳点，运动来自尺度骤变。

**所见题材（不随风格自动迁移）**：红白带状碎片、白色字形和框状物，中央较小黑红球体；文字内容不是分析依据。

## 风格证据

| 维度 | 观察与分析 |
|---|---|
| 构图与留白 | 横幅接近中央汇聚，多条斜向长带从边框切入；近处片体很大，远处细小密集。 |
| 色彩与明度 | 浅灰白主场与珊瑚红硬色块，中央黑红小域最暗；不是大面积真正空白，线片占据全场。 |
| 笔触与形状 | 长尖条、折角、硬片与字形为主，粗细差异大；缺乏R02那种柔软手势笔触。 |
| 边缘与清晰度 | 大部分硬轮廓，部分远处减弱，局部有体积阴影；清晰度用于透视而非消隐实体。 |
| 空间机制 | 尺寸递减、遮挡与汇聚建立强穿行深度，图形似在三维空间展开，非纯二维海报。 |
| 运动与节奏 | 尖锐线条多向交叉，整体有高速向心／穿越感；动势强于R01缓慢下坠。 |
| 材料外观与不确定性 | 硬片、字形挤出或图形渲染般外观；不能确认实际三维软件。 |
| 亮度与光学 | 场景大体明亮，球体有暗亮体积，片体轻微受光；不是黑底能量线。 |

## 感知与文字匹配

加速、侵入、信息拥挤或锋利冲突，语气紧而明亮。

适合突变、撞击、断裂或高速推进；迁移近大远小与硬边方向，不必复用字形、球体或通道。

## 容易误判之处

和R11仅共享红白黑与锐利，空间规则不同；把它纳入R02柔性梦感会改变核心机制。
