# 用户给出的图文对应案例

以下是用户明确提供的图文配对，优先于仅从图片推测的主题标签。它们展示用户希望的**语义主体与形式一起参与**：不是自动把每句话都改成人像，也不是按关键词机械套同一张参考图。

## “人类只是时间的重影” → R10

- **参考图**：[R10原图](../assets/visual-reference-library/暗场与张力/1793461965916.png)；[视觉构成](image-profiles/R10.md)。用户另提供了该画面的低分辨率截图，配对按用户说明记录。
- **文字核心**：“人类”是不可忽略的主体；“时间的重影”说明这些人的存在方式是叠合、错位、流逝与难以分辨的共存。“只是”带有相对时间的渺小感。
- **画面证据**：大量半透明人影在高大空间内重叠、拖影与淡化；重复的建筑结构维持尺度和时间层次。既能辨认人群，又不依赖单个主角。
- **转译原则**：保留群体／人的可感知痕迹，并让重影机制作用于它们；不要求复刻建筑。把人群全部删为无主体的抽象划痕，容易失去“人类”的指向；把人画成清晰肖像且没有叠影又会丢掉“时间的重影”。
- **情感**：可感渺小、流逝与存在的脆弱，但不将这些主观情绪断言为唯一解读。

## “我见观音观自在，我见真武见真我” → R04

- **参考图**：[R04原图](../assets/visual-reference-library/线与人物/1793461857159.png)；[视觉构成](image-profiles/R04.md)。这是一张持剑人形由金色线迹构成的图片；依据图像无法确定人物身份，不宣称其必定描绘某位神祇。
- **文字核心**：观音、真武与“我”构成有具体文化指向的相见与自我观照关系；“观自在”“见真我”给出内在意识与主体关系，不应一概剥离成纯几何线条。
- **画面证据**：人形是主体，持剑姿态与外放金线形成有力量的神性／精神性联想；黑底让线迹和形体成为同一个视觉场。神性联想是结合用户配对的解读，而非对人物身份的考证。
- **转译原则**：可以保留象征性人形、适合语境的神性形象或“见”与“自我”的关系；金色线条、姿态与空间共同组织意义。不必机械画两个神像，也不要一律禁止神祇、人物或剑；具体形象取决于原句、用户要求和新的原创构思。

## 使用边界

两例是用户给出的审美证据，不是“人类→必须画人群”或“神祇→必须画金色持剑人”的固定映射。比较不同主体及构图对这一次原句的作用，保留用户指定的风格取向；不通过关键词强制套图。对没有人物指向的句子也无需硬加人物。用户希望生成原创图时，借用关系与形式机制而非复制原图构图与具体人物。
